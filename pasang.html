  2. Nyalakan sakelar Google Apps Script API sampai berwarna hijau/biru.
  3. Kembali ke halaman ini, lalu ketuk Sudah, lanjutkan.

Terakhir: izinkan server Anda

Server CashKu milik Anda perlu izin sekali untuk menyimpan data ke Google Sheet.

  1. Ketuk Izinkan server. Halaman Google akan terbuka.
  2. Bila muncul peringatan, ketuk Lanjutan → Buka CashKu Server (tidak aman). Developernya adalah akun Anda sendiri.
  3. Ketuk Izinkan, lalu kembali ke halaman ini.
Muncul "Sorry, unable to open the file"? Biasanya karena di HP ini masuk lebih dari satu akun Google.
  1. Ketuk Salin alamat server di bawah.
  2. Buka tab Samaran di Chrome (⋮ → Tab Samaran baru), tempel alamatnya.
  3. Masuk dengan akun , lalu Lanjutan → Buka CashKu Server → Izinkan.
  4. Kembali ke halaman ini, ketuk Sudah saya izinkan.
